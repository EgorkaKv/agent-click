# agent-click

MCP-сервер, через который Claude Code управляет реальным браузером пользователя (Brave/Chrome) так, как это делает человек: видит интерфейс и нажимает на элементы. Задача — пользовательские действия (настройка рекламы в Meta Ads, заполнение форм и т.п.) в залогиненном профиле. Отладка страниц и DOM для агента вне scope.

## Правило документирования (обязательно)

Все важные решения, выводы исследований и договорённости фиксируются в файлах проекта сразу, когда они приняты, а не остаются только в чате (контекст сессии теряется при compact).

- [docs/decisions.md](docs/decisions.md): журнал решений. Новое решение — новая запись с датой, причиной и отвергнутыми альтернативами. Изменённое решение не удаляется, а помечается как замещённое.
- [docs/architecture.md](docs/architecture.md): текущая архитектура и открытые вопросы. Обновляется, когда меняется картина.
- [docs/api-draft.md](docs/api-draft.md): черновик API инструментов для агента (пока решения не приняты, потом переедет в decisions).
- [docs/research/](docs/research/): результаты исследований (чужие решения, замеры, эксперименты).

Перед тем как предлагать архитектурные решения, прочитай эти файлы.

## Окружение пользователя

- Windows 10, браузер Brave 1.98.60 (Chromium 156).
- Профиль Brave: `%LOCALAPPDATA%\BraveSoftware\Brave-Browser\User Data`.
- Node 22, npm 11.
